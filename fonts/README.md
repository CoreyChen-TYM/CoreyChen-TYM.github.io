# Fonts

The active font is Roboto, downloaded from Google Fonts:

- https://github.com/google/fonts/tree/main/ofl/roboto

`roboto-variable.ttf` supports weights 100–900. Its SIL Open Font License
1.1 and copyright notice are included in `Roboto-OFL.txt`.

Previously used Oxygen and Oswald files are retained for reference:

- https://www.kernel.org/theme/fonts/oxygen-regular-webfont.woff2
- https://www.kernel.org/theme/fonts/oswald-regular-webfont.woff2

Both families use the SIL Open Font License 1.1. Included license notices
are from the Google Fonts repository, under ofl/oxygen and ofl/oswald.
